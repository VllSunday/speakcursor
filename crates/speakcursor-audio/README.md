# Захват аудио

Windows-модуль захватывает звук микрофона через CPAL. Он преобразует несколько каналов в моно, затем готовит 16 кГц для локального CTranslate2 и WAV для OpenAI. Физический микрофон в облачной среде недоступен; необходимая проверка на настоящем Windows войдёт только в завершённый первый блок.
