# OpenAI для первой фичи

Rust-клиент для проверки общего API-ключа, списка доступных моделей, облачного распознавания, стилей диктовки и промпт-инженера. Ключ передаётся в вызов и не сохраняется в обычном файле настроек. Выбор совместимых моделей для конкретных задач, защищённое хранилище ключа в Windows, интерфейс настроек и соединение с записью звука ещё нужны до первой пользовательской проверки.
