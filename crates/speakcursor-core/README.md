# SpeakCursor Core

Платформенно-независимая логика будущего Rust-приложения. Реализованы жизненный цикл обычной диктовки и сохраняемая схема настроек первого блока: список локальных моделей, локальное или API-распознавание, стили, словарь замен, отдельное сочетание промпт-инженера и назначения облачных моделей. API-ключ намеренно не сохраняется в файле настроек. Первое нажатие запускает запись в выбранном стиле, второе нажатие того же сочетания завершает её, Esc отменяет запись без распознавания и вставки. До конца обработки новый сеанс не начинается.

Модуль не захватывает звук, не назначает горячие клавиши и не вставляет текст. Повтор именно исходного сочетания подтверждён пользователем. Поведение других сочетаний с иным стилем во время активной записи и после начала обработки остаётся технической заглушкой до проектирования конфликтов клавиш.

```bash
cargo test --manifest-path crates/speakcursor-core/Cargo.toml
```
