# SpeakCursor Core

Платформенно-независимая логика будущего Rust-приложения. Пока реализован только жизненный цикл обычной диктовки: первое нажатие запускает запись в выбранном стиле, второе нажатие того же сочетания завершает её, Esc отменяет запись без распознавания и вставки. До конца обработки новый сеанс не начинается. Общий вызов и отдельный вызов стиля имеют разные идентификаторы сочетаний, даже если выбирают одинаковый стиль.

Модуль не захватывает звук, не назначает горячие клавиши и не вставляет текст. Повтор именно исходного сочетания подтверждён пользователем. Поведение других сочетаний с иным стилем во время активной записи и после начала обработки остаётся технической заглушкой до проектирования конфликтов клавиш.

```bash
cargo test --manifest-path crates/speakcursor-core/Cargo.toml
```
