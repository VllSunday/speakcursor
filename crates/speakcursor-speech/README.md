# Распознавание речи

Новый Rust-модуль для локальных моделей формата CTranslate2, который использовало прежнее приложение с `faster-whisper`. Для первой проверки приоритет — совместимость с уже скачанной моделью `large-v3` из каталога Hugging Face. Модуль принимает каталог с `model.bin`, `config.json`, `tokenizer.json` и `preprocessor_config.json`; отдельный файл whisper.cpp не подходит.

Модуль пока только загружает модель и преобразует готовый монофонический буфер 16 кГц в текст. Запись с микрофона, подготовка аудио, API-распознавание, интерфейс выбора модели и GPU-сборка остаются следующими частями первого крупного блока. Никакой промежуточный билд для пользователя до его завершения не требуется.
