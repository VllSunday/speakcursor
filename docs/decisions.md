# Журнал согласованных решений

Сводка обсуждения 15–16 октября 2026 года. Это смысловая запись решений, не дословная стенограмма. Спецификации дополняются после следующих ответов пользователя.

| --- | --- |

| 2 | Последовательность: функции → сценарии и элементы UI → визуальные макеты → подробные спецификации → стек → реализация и тесты |
| 3 | Основное окно и две плавающие панели; основной UX выходит за пределы меню трея |
| 4 | Пользователь настраивает приложение вручную; мастер запуска и автоматические рекомендации моделей отклонены |
| 5 | Встроенные локальные модели в первой версии — только распознавание речи, CPU/GPU |
| 6 | Локальная модель подключается через простой системный выбор; точный формат и выбор файла/папки зависят от будущего бэкенда |

| 18 | Редактор выделения входит в объём: сокращение, перевод, изменение тона и структуры; способ применения ещё открыт |

| 21 | Нужны запись без удержания и отмена. Восстановление после ошибки желательно при небольшом усложнении |
| 22 | Персонализация: словарь, несколько стилей, правила обработки, возможность привязок для стилей |

| 28 | Стек, финальные макеты, лицензия, точная поддержка GPU и порядок выпуска по ОС пока не выбраны |

## Непринятые предложения

- Мастер первого запуска с автоматической рекомендацией модели — отклонён.
- Хранить только одну заменяемую локальную модель — вместо этого принят список.
- Автоматически переходить на CPU после ошибки GPU — вместо этого требуется согласие.
- Обязательный предпросмотр каждой новой диктовки — вместо этого принята автовставка.
- Прямая поддержка Anthropic или произвольных OpenAI-совместимых провайдеров в первой версии — отложена.

## Что не следует выводить из обсуждения

- Список локальных моделей и каталог API — разные сущности.
- «Аудиомодель» в настройках не добавляет облачное распознавание речи: локальная диктовка остаётся согласованным вариантом; аудиовыход нужен для голоса ассистента.
- Пользователь поправил «видео» на «фото»; обработка видео не добавлялась в объём.
- Отказ от мастера первоначальной настройки не отменяет рабочий режим ассистента.
- Поддержка изображений не равна произвольному управлению кнопками всех приложений.
- Каталог 175 инструментов VoiceOS не является планом реализации всех этих инструментов.
- Автовставка новой диктовки не означает автовставку ответов, результатов Edit или генерации промптов.

Актуальная точка продолжения находится в [передаче контекста](handoff.md).
