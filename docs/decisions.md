# Журнал согласованных решений

Сводка обсуждения 15–16 октября 2026 года. Это смысловая запись решений, не дословная стенограмма. Спецификации дополняются после следующих ответов пользователя.

| --- | --- |
| 1 | Цель — открытое минималистичное настольное приложение, ориентированное на Windows, macOS и Linux. Окончательный порядок выпуска по ОС не утверждён; предварительный план приведён ниже |
| 2 | Последовательность: функции → сценарии и элементы UI → визуальные макеты → подробные спецификации → стек → реализация и тесты |

| 25 | Финальный выбор облачного провайдера первой версии — только OpenAI. Предыдущая идея универсальных совместимых подключений и Anthropic отложена |

| 37 | Обновлять каталог при открытии раздела «Модели» и по кнопке «Обновить список», сохраняя назначенные пользователем модели |

| 39 | Хранить в одной записи истории диктовки исходную расшифровку и итог после LLM-обработки; для диктовки без обработки достаточно одного текста |
| 40 | История диктовки хранится 30 дней по умолчанию; доступны «Не удалять автоматически» и полная очистка. Произвольный срок хранения пока не предусматривается |
| 41 | Если первоначальная LLM-обработка не удалась, разрешить повтор из истории по сохранённой исходной расшифровке без новой диктовки. Повтор уже успешных записей пока не согласован; отображение результата исторического повтора уточнено в решении 42 |

| 52 | Отдельные настраиваемые сочетания открывают верхний чат и запускают голосовой ввод. В чате можно вводить или вставлять текст и отправлять запрос; дополнительные сочетания для стилей обработки необязательны |

## Предварительные планы

- Пользователь предполагает сначала выпустить версию для Windows, затем подготовить сборки для Linux и macOS. Это пока план, не окончательное решение об очередности, сроках или поддержке возможностей по ОС.

## Непринятые предложения

- Мастер первого запуска с автоматической рекомендацией модели — отклонён.
- Хранить только одну заменяемую локальную модель — вместо этого принят список.
- Автоматически переходить на CPU после ошибки GPU — вместо этого требуется согласие.
- Обязательный предпросмотр каждой новой диктовки — вместо этого принята автовставка.
- Прямая поддержка Anthropic или произвольных OpenAI-совместимых провайдеров в первой версии — отложена.
