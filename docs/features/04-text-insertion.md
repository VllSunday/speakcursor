# Вставка текста

Статус: основные правила вставки и поведение при неудачной вставке согласованы. Детали по ОС, управление фокусом и критерии определения результата вставки ещё предстоит уточнить.

## Согласовано

- Успешная новая диктовка сразу вставляется в исходное поле во всех трёх режимах обработки. Если текст выделен, результат диктовки заменяет выделение. Диктовка и команды редактирования/анализа вызываются раздельно.
- После успешного повтора облачной обработки результат также сразу вставляется в исходное поле без дополнительного подтверждения.
- Сохраняются вставка в приложения и терминалы, имитация ввода и восстановление прежнего содержимого буфера при обычной успешной автовставке. Точные настройки и реализация по ОС ещё не определены.
- Ответы ассистента и на вопросы по экрану показываются в верхней панели. Редактор выделения показывает предпросмотр и сразу копирует результат в буфер для применения через Ctrl+V или кнопку вставки. Готовый промпт сразу вставляется в исходное поле без предпросмотра.

## Неудачная вставка: принятое решение

Если исходное окно закрыто или вставка не удалась:

- Скопировать готовый текст в системный буфер для ручной вставки.
- После успешного копирования показать сообщение «Не удалось вставить текст — он скопирован» в верхней панели. Она плавно появляется автоматически и примерно через пару секунд плавно закрывается.
- Оставить текст в буфере, чтобы пользователь мог вставить его обычным сочетанием вставки, например Ctrl+V. Прежнее содержимое буфера автоматически не восстанавливать в этом сценарии.

Готовый текст здесь — результат выбранного режима диктовки, включая успешную облачную обработку, если она применялась.

Отдельный сценарий ошибки самой облачной обработки описан в [облачной обработке](03-cloud-processing.md): в буфер попадает исходный распознанный текст, а верхняя панель предлагает повтор или вставку без обработки.

## Открытые детали

- Как определить успешность или неудачу вставки в разных приложениях и ОС; надёжное обнаружение каждого сбоя пока не подтверждено.
- Смена активного окна или поля во время обработки и управление фокусом.
- Поведение при ошибке самого копирования: сообщение об успешном копировании должно соответствовать результату операции.
- Настройки способов вставки и поддержка терминалов по ОС.
- Точная длительность и анимация верхней панели для сообщения об ошибке уточняются на макетах; ориентир — пара секунд.
