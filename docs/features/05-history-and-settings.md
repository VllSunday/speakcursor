# История и служебные настройки

Статус: согласованы состав записи истории диктовки, хранение 30 дней по умолчанию, отключение автоудаления и полная очистка. Также согласован повтор из истории после ошибки первоначальной LLM-обработки. Остальные действия и интерфейс ещё обсуждаются.

## История диктовки: принятое решение

- Хранить в одной записи исходную расшифровку и итог после LLM-обработки, если она применялась.
- Для диктовки без дополнительной обработки достаточно одного текста.
- Это два варианта текста одной диктовки, а не две отдельные записи истории.
- В первой версии нужен обычный текстовый поиск по исходной расшифровке и результату обработки. Найденное показывается простым списком записей, без расширенного поиска.
- В найденной записи исходная расшифровка показана слева, итог после обработки — справа. У каждого варианта своя иконка копирования сбоку: пользователь одним нажатием выбирает, какой текст поместить в буфер.
- Если обработки не было, показывается один текст с одной иконкой. Для длинного текста допустим компактный фрагмент в списке; копирование должно брать полный текст.

Сохранение аудиозаписей этим решением не согласовано. Историю диалогов ассистента и результатов других функций нужно обсудить отдельно.

## Хранение и очистка: принятое решение

- По умолчанию история хранится 30 дней с автоматическим удалением более старых записей.
- Доступен вариант «Не удалять автоматически».
- Доступно действие полной очистки истории.
- Выборочное удаление отдельных записей пока отложено; пользователь не считает его необходимым на текущем этапе.
- Произвольный срок хранения пока не предусматривается: текущий выбор — 30 дней или отключение автоудаления.

Это текущее решение для истории диктовки. Подтверждение полной очистки, точный момент отсчёта срока и влияние повторной обработки на срок хранения ещё предстоит уточнить.

## Повтор после ошибки из истории: принятое решение

- Если первоначальная LLM-обработка завершилась ошибкой, пользователь может повторить её из истории по сохранённой исходной расшифровке, без новой диктовки.
- Исходный распознанный текст должен быть доступен в записи с неудачной обработкой.
- Подтверждён сценарий восстановления после ошибки. Повторная обработка уже успешных записей, смена режима или модели при повторе пока не согласованы.
- Успешный результат повтора из истории показывается в той же записи. Исходная расшифровка сохраняется. Это отдельный сценарий от повтора в текущей диктовке, где уже согласована автовставка. Конкретные действия с текстом записи уточняются далее.

## Автозапуск: принятое решение

- Автозапуск включён по умолчанию: приложение запускается при входе пользователя в систему после запуска компьютера.
- В настройках пользователь может отключить автозапуск переключателем. Точная подпись переключателя ещё не утверждена.
- Реализация и ограничения по ОС выбираются позднее вместе со стеком.

## Закрытие окна и выход: принятое решение

- Крестик скрывает основное окно; приложение остаётся в трее и продолжает реагировать на горячие клавиши.
- Полное завершение приложения выполняется отдельным действием «Выйти» в меню трея.

## Существующая основа

Текущая реализация сохраняет последние 20 текстов. Этот лимит не утверждён как требование новой версии. Новая версия пока не реализована.

## Открытые вопросы

- Подтверждение полной очистки и точные правила отсчёта срока хранения.
- Точная длина компактного фрагмента в списке и просмотр полного текста; выборочное удаление пока отложено.
- Визуальное отображение ошибки и состояний повтора; результат успешного повтора показывается в той же записи.
- Объём истории других функций и связь с диалогами ассистента.
- Детали автозапуска и сочетаний клавиш. Жизненный цикл локальной модели описан в [локальной диктовке](01-local-dictation.md).
