# Редактор выделенного текста

Статус: согласованы предпросмотр, немедленное копирование результата в буфер и применение через Ctrl+V или кнопку вставки. Согласованы голосовые и текстовые команды через минималистичную верхнюю панель с раскрываемой историей. Диктовка и команды вызываются раздельно; группировка редактирования и анализа внутри команд ещё обсуждается.

## Уже согласовано

- Редактирование существующего выделенного текста: сокращение, перевод, изменение тона и структуры.
- Обработка выполняется через OpenAI с общим ключом и назначенной для задачи моделью.
- Способ применения результата согласуется отдельно от автовставки новой диктовки.

## Задание команды и верхняя панель: принятое решение

- Пользователь может написать инструкцию или произнести её голосом; оба способа запускают одинаковую обработку выделенного текста.
- Верхняя диалоговая панель — минималистичный чат: одно поле ввода и кнопка «Отправить».
- Панель можно раскрыть для просмотра истории переписки.
- Ответ отображается постепенно по мере поступления от модели, с быстрой плавной анимацией без искусственного замедления. Общие правила — в [направлении интерфейса](../ui/interface-direction.md#потоковое-отображение-ответов).
- Конкретные размеры, раскрытие, запуск голосового ввода и момент отправки голосовой команды ещё предстоит спроектировать.
- История переписки в панели не приравнивается автоматически к истории диктовок: её состав, хранение и контекст запросов ещё не согласованы.

## Раздельные режимы: принятое решение

- Диктовка и команды к выделенному тексту вызываются раздельно. Пользователь выбрал явное разделение логики вместо универсального вызова, автоматически угадывающего действие по наличию выделения.
- В режиме диктовки речь — новый текст: результат вставляется в поле, а при наличии выделения заменяет его. Применяется выбранный режим или стиль обработки диктовки.
- Редактирование или анализ выделенного текста вызываются отдельным сочетанием от диктовки; речь в этом режиме служит инструкцией к тексту.
- Само наличие выделения не переключает диктовку в режим команд.
- Для текстовых команд остаётся отдельный вызов верхнего чата; выделение автоматически подхватывается как контекст, вручную переносить его не нужно.
- Нужно ещё решить, объединены ли редактура и анализ в один режим команд или имеют разные вызовы.
- Дополнительные сочетания для стилей обработки необязательны. Конкретные клавиши не выбраны; пробел остаётся примером.
- Пример «классического» стиля с исправлением пунктуации не заменяет ранее согласованный исходный режим «Без обработки»: изменение значения по умолчанию не утверждено.

## Предпросмотр и применение: принятое решение

- Результат постепенно появляется в предпросмотре; готовый результат сразу копируется в системный буфер обмена по завершении генерации. Потоковый предпросмотр не означает автоматическую вставку частичного текста в исходное поле.
- Пользователь может применить его вручную через Ctrl+V или нажать кнопку вставки в панели; точная подпись кнопки уточняется при проектировании интерфейса.
- Автоматической замены выделения при получении результата нет.
- Пока пользователь выбирает действие, результат остаётся в буфере для ручной вставки; прежнее содержимое буфера автоматически не восстанавливается в этот момент.
- Управление фокусом и сохранение исходного выделения для вставки кнопкой нужно проработать отдельно.

## Точка продолжения

Уточнение результата в том же диалоге согласовано: пользователь может продолжить командой «ещё короче» голосом или текстом без повторного выделения. Контекст исходного выделения сохраняется в рамках текущей работы. Другие вопросы редактора остаются открытыми; следующий блок — [помощь по экрану](07-screen-help.md). Группировка редактирования и анализа остаётся открытой; диктовка и команды разделены.

## Открытые вопросы

- Вызов редактора, запуск и отправка голосовой команды; необходимость готовых действий.
- Отмена и закрытие предпросмотра, сохранение выделения и буфер после применения.
- Поведение при отсутствии выделения, потере целевого поля или ошибке API.
- Срок жизни контекста, история уточнений и восстановление исходного текста.
