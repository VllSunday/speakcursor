# Подготовка промптов

Статус: самостоятельная функция включена в первую версию; отдельный вызов и преобразование надиктованного текста в промпт согласованы. Готовый промпт сразу вставляется в исходное поле без предпросмотра. Прикрепление изображения отложено.

## Согласовано

- Пользователь вызывает подготовку промпта отдельным настраиваемым сочетанием клавиш и надиктовывает задачу.
- Речь распознаётся выбранным пользователем способом — локально или через API, затем через OpenAI преобразуется в очищенный и структурированный запрос для ИИ с назначенной для этой задачи моделью.
- Это самостоятельная функция, а не другое название структурирования обычной диктовки или работы с выделением.
- В первой версии входом служит надиктованная задача без прикрепления изображения. Изображения для этого режима — возможное расширение после первой версии; это не ограничивает отдельную функцию помощи по экрану.
- Конкретное сочетание клавиш пока не выбрано.
- После завершения генерации готовый промпт сразу вставляется в исходное поле без предпросмотра и дополнительного подтверждения.

## Точка продолжения

Базовый сценарий согласован. Следующий этап — сводка требований первой версии и выбор стека; актуальное состояние — в [передаче контекста](../handoff.md).

- Правила формирования промпта и допустимость уточняющих вопросов.
- Способ прикрепления изображений в будущей версии.
- История, повторные уточнения, ошибки и отмена.
