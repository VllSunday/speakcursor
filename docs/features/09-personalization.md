# Персонализация: словарь и стили

Статус: четыре варианта обработки диктовки согласованы; словарь ещё обсуждается.

## Согласовано

- Нужны словарь, несколько стилей обработки речи и пользовательские правила обработки.
- Для стилей можно назначать дополнительные сочетания клавиш; общая клавиша диктовки использует выбранный режим по умолчанию. Дополнительные сочетания необязательны.
- Исходный режим диктовки — «Без обработки». Пример стиля с правкой пунктуации не изменяет это значение по умолчанию.
- Три готовых варианта: «Без обработки» (только локальная расшифровка), исправление пунктуации и ошибок в словах без переформулирования, структурирование надиктованного текста для ТЗ или README.
- Четвёртый вариант — один пользовательский стиль: человек вводит и сохраняет свой промпт с правилами обработки расшифровки. Для него можно назначить отдельное сочетание, а также выбрать его для общего вызова диктовки по умолчанию.
- Словарь первой версии — список пар «как распознано → как написать». Замены применяются локально к расшифровке и работают даже в режиме «Без обработки», без API-ключа и облачного обращения.

## Точка продолжения

Стили и базовый формат словаря определены. Следующий базовый блок — голосовые ответы ассистента: автоматическое озвучивание или запуск по действию пользователя. Правила совпадения словарных замен уточнить при полной спецификации.

## Открытые вопросы

- Подписи готовых стилей в интерфейсе, название пользовательского стиля и правка его промпта.
- Правило при конфликте сочетаний.
- Редактирование словарных пар, регистр и границы слова; возможность передавать словарь как подсказку распознавателю уточняется при выборе бэкенда.
- Поведение пользовательских правил при режиме «Без обработки» и при недоступности OpenAI.
