# Ассистент и голосовые ответы

Статус: базовый диалог и переключатель озвучивания согласованы; подробные состояния и значения по умолчанию уточняются при полной спецификации.

## Согласовано

- Верхняя плавающая панель вызывается отдельным сочетанием и содержит минималистичный чат: поле ввода, кнопку «Отправить» и раскрываемую историю переписки.
- Вопрос можно набрать или задать голосом. Ассистент поддерживает уточнения в диалоге и поиск в интернете через возможности выбранного сервиса.
- Текст ответа всегда показывается в верхней панели по мере генерации, с быстрой плавной анимацией без искусственного замедления; его можно скопировать.
- Озвучивание ответов агента включается и выключается переключателем в настройках. При включении ответы произносятся автоматически; при выключении остаются только текстом в панели. Отдельная кнопка «Озвучить» у каждого ответа не является обязательным основным способом управления.
- Для облачных задач используется общий ключ OpenAI; модель для синтеза речи выбирается отдельно в разделе моделей.

## Открытые вопросы для полной спецификации

- Исходное положение переключателя озвучивания и остановка воспроизведения.
- Время хранения переписки и связь с общей историей диктовки.
- Состояния поиска, источники, ошибки синтеза речи и отсутствие совместимой модели.
