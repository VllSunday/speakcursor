# Ассистент и голосовые ответы

Статус: блок агента реализуется после проверки экранного режима. Исходники уже содержат чат, голосовой ввод, работу с выделенным текстом, поиск и озвучивание; проверки на Windows и общий пользовательский выпуск ещё впереди. Отдельный билд для визуальной правки следа мыши не выпускается.

## Реализация для общего выпуска

- Настраиваемое сочетание открывает верхнюю панель агента. Выделенный текст захватывается через копирование из исходного приложения с восстановлением прежнего содержимого буфера; если выделения нет, панель открывается как обычный чат. Изменение выделения начинает новый контекст. Конкретную работу восстановления буфера в сторонних приложениях нужно проверить на Windows.
- В панели доступны текстовый вопрос и голосовой вопрос через кнопку записи. Ответ поступает по мере генерации, в том числе в раскрытой истории; ссылки из поиска можно открыть вручную. Запрос «ещё короче» использует историю диалога и тот же выделенный текст.
- Результат по выделенному тексту копируется в буфер и остаётся в предпросмотре. Его можно вставить вручную через Ctrl+V или кнопкой «Вставить», которая возвращает исходное окно и проверяет его перед вставкой. Если вставка не удалась, текст остаётся в буфере.
- Один ключ OpenAI используется для чата, работы с выделением и синтеза речи; модель выбирается отдельно для каждой задачи. Поиск включается при явном поисковом запросе. Автоматическое озвучивание по умолчанию выключено; пользователь включает его в настройках и выбирает голос и модель. Текст ответа остаётся доступен при ошибке озвучивания. Кнопка «Тише» останавливает воспроизведение.
- Если для запроса не заданы ключ или модель, сообщение в панели открывает нужный раздел настроек по клику. Это переход к разделу; согласованная краткая анимация фокуса на конкретном поле ещё не реализована.
- Переписка в текущей реализации хранится в памяти запущенного приложения; срок хранения между запусками остаётся отдельным решением.

## Согласовано

- Верхняя плавающая панель вызывается отдельным сочетанием и содержит минималистичный чат: поле ввода, кнопку «Отправить» и раскрываемую историю переписки.
- Вопрос можно набрать или задать голосом. Ассистент поддерживает уточнения в диалоге и поиск в интернете через возможности выбранного сервиса.
- Текст ответа всегда показывается в верхней панели по мере генерации, с быстрой плавной анимацией без искусственного замедления; его можно скопировать.
- Озвучивание ответов агента включается и выключается переключателем в настройках. При включении ответы произносятся автоматически; при выключении остаются только текстом в панели. Отдельная кнопка «Озвучить» у каждого ответа не является обязательным основным способом управления.
- Для облачных задач используется общий ключ OpenAI; модель для синтеза речи выбирается отдельно в разделе моделей.

## Остаётся проверить на Windows

- Захват выделенного текста и восстановление прежнего буфера в обычных редакторах и браузере; применение результата кнопкой в исходное поле.
- Реальный потоковый ответ, поиск с источниками, голосовой вопрос и озвучивание через выбранную модель.
- Хранение переписки между запусками и связь с общей историей пока не согласованы; текущий диалог доступен в памяти до выхода из приложения.
