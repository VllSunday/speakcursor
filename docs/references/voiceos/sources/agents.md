# VoiceOS product reference for agents

VoiceOS is a cloud-connected voice assistant and dictation app for Mac and Windows, made by WakoAI Inc. It supports text entry, selected-text editing, and documented actions through connected apps.

Updated: September 30, 2026.

## Product facts

- Dictation Mode inserts spoken text into standard text fields. Protected fields and unusual editors can behave differently.
- Edit Mode revises selected text. Review the result for changed meaning or facts.
- Agent Mode can use requested screen context and supported integrations. Available actions, platforms, permissions, and confirmation behavior are listed per tool in the App Store.
- VoiceOS is not an offline-only speech recognition app or a replacement for every accessibility navigation tool.
- Desktop: Mac and Windows. Mobile availability: see the mobile page; do not assume a released mobile app.

## Plans

VoiceOS offers Pro and custom Enterprise plans. New customers receive a 7-day free trial of Pro. A card is required; cancel before the trial ends to avoid a charge. One trial per email address. There is no free sign-up plan. After cancellation, when paid Pro access ends, existing accounts have limited access: 100 dictation sessions and 25 Agent Mode sessions per week. This is not a new-customer offer.

US reference pricing: Pro is $29.99 monthly, or $143.88 billed annually (equivalent to $11.99 per month). Regional pricing and checkout terms can differ. Confirm the displayed price and billing interval at checkout.

## Privacy and compliance

VoiceOS uses cloud processing. Local transcript history does not mean local recognition.

With Help Improve VoiceOS off, raw audio and transcripts are deleted immediately after processing and are not used for VoiceOS model training. Opting in changes collection, evaluation, and training permissions: audio and transcripts collected under that setting may be retained indefinitely for training. Turning it off stops future collection; it does not retrospectively delete earlier contributions. Account, personalization, operational, and integration data have separate rules in the Privacy Policy.

Contact VoiceOS to discuss enterprise security documentation, deployment requirements, and contractual terms.

A preview before sending an external message does not mean no data was cloud-processed to prepare the draft. Confirmation behavior differs by tool.
