Один общий предрелиз для проверки диктовки, экранного режима и агента. В него включён мягкий след курсора, который исчезает примерно за полсекунды. Агент добавляет чат с потоковым ответом, голосовой вопрос, работу с выделенным текстом, ссылки веб-поиска и настраиваемое озвучивание.

Инструкция `COMBINED_TEST.md` находится в архиве вместе с `SpeakCursor.exe`. Сборка и тесты в GitHub Actions проверяют код, но реальную работу микрофона, выделения текста, буфера обмена, окон и звука нужно подтвердить на Windows.
