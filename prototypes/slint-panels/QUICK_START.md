# Проверка диктовки SpeakCursor

Распакуйте архив в постоянную папку и запустите `SpeakCursor.exe`. Откроются настройки; после закрытия окна приложение останется в системном трее. Из трея можно снова открыть настройки, историю или полностью выйти.

Для локального распознавания укажите папку уже скачанной модели `faster-whisper` в формате CTranslate2. Нужна папка с `model.bin`, `config.json`, `tokenizer.json` и `preprocessor_config.json`; старая модель `large-v3` обычно находится в кэше Hugging Face и может определиться автоматически. Если настройки показывают «Найдена модель», нажмите «Сохранить»: только после этого она станет выбранной. Статус «Выбрана» означает, что необходимые файлы найдены; загрузка весов происходит при первой диктовке. В этом архиве локальная модель работает на CPU. Для распознавания через API включите OpenAI и сохраните один ключ. Ключ хранится зашифрованным средствами Windows отдельно от файла настроек. В разделе «Модели API» выберите отдельно модель распознавания, обработки текста и промпт-инженера; каталог загружается после сохранения ключа и обновляется кнопкой. Можно также вписать ID модели вручную. Сохранение автоматически проверяет доступность выбранных облачных моделей реальными запросами.

Откройте поле ввода, например в Блокноте. Основное сочетание по умолчанию — `Ctrl+Alt+F8`: нажмите его, продиктуйте текст и нажмите то же сочетание снова. Во время записи полоски на нижней плашке реагируют на фактический звук с микрофона. `Esc` отменяет запись. По умолчанию текст вставляется без облачной обработки. Стиль для основного сочетания и дополнительные сочетания для каждого стиля меняются в настройках; промпт-инженер по умолчанию вызывается через `Ctrl+Alt+F9` и сразу вставляет готовый промпт.

Если облачная обработка не удалась, верхняя панель предложит повторить её или вставить исходную расшифровку; исходный текст также сразу копируется в буфер. Если вставка не удалась, верхняя панель сообщит об этом, а текст останется в буфере для `Ctrl+V`. История хранится 30 дней, если не включено «Не удалять историю автоматически»; в ней можно найти и отдельно скопировать исходную расшифровку или результат обработки.

Этот архив предназначен для одной полной проверки первого блока на Windows. Указание мышью на экран и чат агента пока не входят в него.
