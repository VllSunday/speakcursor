# Проверка диктовки SpeakCursor

Распакуйте архив в постоянную папку и запустите `SpeakCursor.exe`. Откроются настройки; после закрытия окна приложение останется в системном трее. Из трея можно снова открыть настройки, историю или полностью выйти.

Для локального распознавания укажите папку уже скачанной модели `faster-whisper` в формате CTranslate2. Нужна папка с `model.bin`, `config.json`, `tokenizer.json` и `preprocessor_config.json`; старая модель `large-v3` обычно находится в кэше Hugging Face и может определиться автоматически. В этом архиве локальная модель работает на CPU. Для распознавания через API включите OpenAI, введите один ключ и название модели распознавания. Ключ хранится зашифрованным средствами Windows отдельно от файла настроек. Для стилей обработки и промпт-инженера укажите отдельные модели в тех же настройках. Сохранение автоматически проверяет доступность выбранных облачных моделей.

Откройте поле ввода, например в Блокноте. Основное сочетание по умолчанию — `Ctrl+Alt+F8`: нажмите его, продиктуйте текст и нажмите то же сочетание снова. `Esc` отменяет запись. По умолчанию текст вставляется без облачной обработки. Стиль для основного сочетания и дополнительные сочетания для каждого стиля меняются в настройках; промпт-инженер по умолчанию вызывается через `Ctrl+Alt+F9` и сразу вставляет готовый промпт.

Если вставка не удалась, верхняя панель сообщит об этом, а текст останется в буфере обмена для `Ctrl+V`. История хранится 30 дней, если не включено «Не удалять историю автоматически»; в ней можно найти и отдельно скопировать исходную расшифровку или результат обработки.

Этот архив предназначен для одной полной проверки первого блока на Windows. Указание мышью на экран и чат агента пока не входят в него.
