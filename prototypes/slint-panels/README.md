# Windows-приложение SpeakCursor на Slint

Первый крупный блок опубликован как предрелиз диктовки. По первому отзыву пользователя базовая диктовка работает; облако, все стили и история на его машине ещё не проверены. Сейчас разрабатывается второй блок: голосовые запросы по экрану с указанием курсором. Пользователь получит следующий Windows-билд только после завершения всего второго блока.

## Готовый Windows-билд

Актуальный пользовательский билд первого блока — `dictation-preview-v0.3.1`. Более ранние `windows-preview-v0.1.0` и `windows-preview-v0.2.0` показывают только работу окон. Ветка экранного режима пока не выпускается для ручной проверки.

Для проверки сохранения фокуса запустите из PowerShell в распакованной папке `./speakcursor-slint-panels.exe --focus-probe`. За три секунды переключитесь в Блокнот. После появления панелей в терминале появятся два результата `PASS` или `FAIL`; курсор ввода должен оставаться в Блокноте. Если проверка показала `FAIL`, запишите, на каком шаге это произошло, и какое окно оказалось активным.

Проверка первого Windows prerelease пользователем: оба результата `PASS` (сразу после показа и через 250 мс), ввод в Блокноте работает при открытых панелях и после клика по нижней плашке. В первом билде плашка была пассивной. Новые обработчики записи и вставки на Windows ещё не проверены.

## Сборка из исходников

```bash
cd prototypes/slint-panels
cargo run
```

При сборке из исходников проверка фокуса запускается командой `cargo run -- --focus-probe`. Пробник показывает реальное поведение, но не доказывает работу во всех приложениях. Для варианта с NVIDIA CUDA потребуется сборка с `--features cuda` и установленный CUDA Toolkit. Ключ OpenAI сохраняется отдельно от настроек в зашифрованном хранилище Windows.

При следующей Windows-проверке вместе с оставшимися сценариями диктовки предстоит проверить отдельное сочетание экранного режима, след курсора без перехвата мыши, один и два монитора, отмену по Esc, облачный ответ и повтор после ошибки. Верхняя панель ошибок и нижняя плашка не должны забирать фокус у поля ввода. Облачная Linux-среда без рабочего стола не подтверждает это поведение.

В меню трея есть «О программе» с виджетом AboutSlint для атрибуции по royalty-free лицензии Slint 1.18.1. Собственную лицензию SpeakCursor пользователь пока не выбрал.
