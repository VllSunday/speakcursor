# Windows-приложение SpeakCursor на Slint

Первый крупный блок опубликован как предрелиз диктовки; базовая диктовка работает по первому отзыву пользователя. Второй блок — голосовые запросы по экрану с указанием курсором — пользователь также проверил: вопросы по изображению работают. Третий блок, агент с чатом, выделенным текстом и озвучиванием, вошёл в общий Windows-предрелиз вместе с мягким затухающим следом мыши. Реальное поведение новых функций на машине пользователя ещё предстоит проверить.

## Готовый Windows-билд

Актуальный общий билд трёх блоков — [`combined-preview-v0.5.0`](https://github.com/VllSunday/speakcursor/releases/tag/combined-preview-v0.5.0). Скачанный ZIP проверен на целостность; внутри `SpeakCursor.exe` и `COMBINED_TEST.md`. Нативные Windows-тесты и сборка прошли в GitHub Actions. Предыдущие пользовательские билды — `screen-preview-v0.4.0` и `dictation-preview-v0.3.1`.

Для проверки сохранения фокуса запустите из PowerShell в распакованной папке `./SpeakCursor.exe --focus-probe`. За три секунды переключитесь в Блокнот. После появления панелей в терминале появятся два результата `PASS` или `FAIL`; курсор ввода должен оставаться в Блокноте. Если проверка показала `FAIL`, запишите, на каком шаге это произошло, и какое окно оказалось активным.

Проверка первого Windows prerelease пользователем: оба результата `PASS` (сразу после показа и через 250 мс), ввод в Блокноте работает при открытых панелях и после клика по нижней плашке. В первом билде плашка была пассивной. Новые обработчики записи и вставки на Windows ещё не проверены.

## Сборка из исходников

```bash
cd prototypes/slint-panels
cargo run
```

При сборке из исходников проверка фокуса запускается командой `cargo run -- --focus-probe`. Пробник показывает реальное поведение, но не доказывает работу во всех приложениях. Для варианта с NVIDIA CUDA потребуется сборка с `--features cuda` и установленный CUDA Toolkit. Ключ OpenAI сохраняется отдельно от настроек в зашифрованном хранилище Windows.

При пользовательской Windows-проверке вместе с оставшимися сценариями диктовки предстоит проверить новый затухающий след, один и два монитора, отмену и повтор экранного запроса. Для агента нужно проверить захват выделения и сохранение буфера, редактирование, поиск, голосовой вопрос и опциональное озвучивание. План одной общей проверки находится в `COMBINED_TEST.md`. Облачная Linux-среда без рабочего стола не подтверждает поведение окон и устройств Windows.

В меню трея есть «О программе» с виджетом AboutSlint для атрибуции по royalty-free лицензии Slint 1.18.1. Собственную лицензию SpeakCursor пользователь пока не выбрал.
