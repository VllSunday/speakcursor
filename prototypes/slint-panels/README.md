# Прототип плавающих панелей Slint

Изолированный прототип двух независимых окон новой версии: верхняя панель потокового ответа и нижняя плашка записи. Оба окна создаются в Rust, без HTML/JavaScript. Текст и индикатор записи анимируются демонстрационным таймером; микрофон, модель, API и глобальные сочетания пока не подключены. Кнопка закрытия верхней панели завершает прототип.

## Готовый Windows-билд

Скачайте архив из последнего prerelease `Windows preview` в GitHub Releases, распакуйте его и запустите `speakcursor-slint-panels.exe`. Прототип сразу показывает две панели. Это демонстрация окон, а не полноценная версия SpeakCursor: ввод и кнопки будущего чата пока не подключены.

Для проверки сохранения фокуса запустите из PowerShell в распакованной папке `./speakcursor-slint-panels.exe --focus-probe`. За три секунды переключитесь в Блокнот. После появления панелей в терминале появятся два результата `PASS` или `FAIL`; курсор ввода должен оставаться в Блокноте. Если проверка показала `FAIL`, запишите, на каком шаге это произошло, и какое окно оказалось активным.

## Сборка из исходников

```bash
cd prototypes/slint-panels
cargo run
```

При сборке из исходников проверка фокуса запускается командой `cargo run -- --focus-probe`. Пробник показывает реальное поведение, но не доказывает работу во всех приложениях. Если первое сообщение `FAIL`, стиль неактивирующего окна применяется слишком поздно — тогда нужно создавать окно с ним ещё до первого показа.

Первый приоритет Windows-проверки — панели поверх других окон и сохранение фокуса исходного приложения. Верхняя панель при открытии только для ответа/ошибки и нижняя плашка не должны забирать фокус; интерактивный чат позже должен получать фокус по явному действию пользователя. После этого проверить прозрачные углы, тени, размещение на активном мониторе, анимацию и несколько мониторов. Облачная Linux-среда без рабочего стола не подтверждает эти свойства. Координаты окон в `main.rs` сейчас фиксированы только для демонстрации двух поверхностей.

Slint 1.18.1 распространяется, в частности, по royalty-free лицензии для настольных приложений с требованием атрибуции (экран AboutSlint или публичный значок); итоговый способ атрибуции следует выбрать перед выпуском. Собственную лицензию SpeakCursor пользователь пока не выбрал.
