# Windows preview: управление тестовым сеансом

Второй проверочный билд новой версии SpeakCursor на Rust и Slint.

- Верхняя панель демонстрирует потоковое появление ответа.
- Нижняя плашка показывает состояние тестового сеанса: `Ctrl+Alt+F8` начинает и завершает его, `Esc` отменяет.
- Обе панели показываются поверх других окон.
- Режим `--focus-probe` проверяет, остаётся ли активным исходное приложение при появлении панелей.

Скачайте ZIP-архив ниже, распакуйте и запустите `speakcursor-slint-panels.exe`. Для проверки фокуса следуйте инструкции в приложенном `README.md`.

Это ранний прототип интерфейса и горячей клавиши. В этом билде звук **не записывается**; распознавание, вставка текста и работа с OpenAI ещё не подключены. В предыдущем билде пользователь подтвердил сохранение ввода в Блокноте при появлении панелей и после клика по плашке.
