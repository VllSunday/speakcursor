# Проверка экранного режима на Windows

Это сборка для **второй крупной проверки**. В ней остаются диктовка и настройки из предыдущего выпуска; добавлена помощь по экрану с указанием мышью.

1. Открой `SpeakCursor.exe` и в настройках выбери локальное или облачное распознавание речи. Для анализа экрана нужен сохранённый ключ OpenAI и отдельная модель в строке «Экран и изображения» раздела «Модели API».
2. По умолчанию экранный режим вызывается `Ctrl+Alt+F10`. Первое нажатие включает микрофон и отслеживание мыши, второе заканчивает запись и сразу отправляет запрос. `Esc` отменяет сеанс без отправки.
3. Скажи вопрос о тексте или изображении на экране и проведи мышью рядом с ним без нажатия кнопки. Порядок речи и движения произвольный. Проверь, что след виден, но мышь продолжает управлять исходным приложением.
4. Проверь вопрос без движения мыши: отправляться должен только монитор под курсором. Затем проведи мышью по двум мониторам за один сеанс и сравни ответ. Второй монитор должен участвовать только после захода на него курсора.
5. Ответ появится в верхней панели. Его можно скопировать; поисковые ссылки можно открыть вручную. В другое приложение ответ сам не вставляется.
6. Если отправка полного запроса оборвётся, в верхней панели появится «Повторить»: вопрос и снимки хранятся в памяти до повтора, нового экранного сеанса или выхода из приложения. Ошибка захвата или распознавания не отправляет неполный запрос.

Экранный режим использует снимки текущего содержимого мониторов. Перед проверкой убери с экрана данные, которые не хочешь передавать выбранной модели OpenAI. Снимки не сохраняются на диск приложением.

Если что-то не сработало, запиши: источник распознавания, выбранную модель экранного режима, число мониторов, какое действие выполнял, текст ошибки и что ожидал увидеть. Не присылай API-ключ.
